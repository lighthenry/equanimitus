I hope you enjoy and find value in some of the things I write here. The site has been built using hakyll - a static site compiler library. It was the best way I found to allow me to write posts using markdown files in lightweight apps like notepad++. Using the haskell language, this compiler then converts these raw files into html - shaping them about the templates I have created. It streamlines the computer power deployed.
