Today I’m testing the new ChatGPT-6 and its integration with [GitHub]{.glossary definition="A platform for storing code, tracking changes and collaborating on projects using Git."}, using this blog as a small experiment. So far, I’ve connected my account, found the equanimitus repository, and asked it to help write this post. There’s something satisfying about bringing an old project back into use through a simple conversation.

The next step is to see how smoothly we can take this draft through to publication on [GitHub Pages]{.glossary definition="A GitHub service that publishes a website from files in a repository."}. For now, it’s a modest test: two paragraphs, one repository, and a chance to explore whether these tools can make keeping a personal website a little easier.
