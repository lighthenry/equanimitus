Today I’m testing the new ChatGPT-6 and its integration with GitHub, using this blog as a small experiment. The next step is to see how smoothly we can take this draft through to publication on GitHub Pages. For now, it’s a modest test: two paragraphs, one repository, and a chance to explore whether these tools can make keeping a personal website a little easier.
